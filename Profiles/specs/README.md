# ชุดค่าตั้ง (set) ของ spec ต่าง ๆ ที่ใช้ในโครงงาน

โหลดไฟล์ `.set` ใน MT5 ผ่าน Strategy Tester → Inputs → Load (หรือ Expert Properties → Load) แล้วเลือก EA `KNARES`
ไฟล์ `Profiles/KNARES_FINAL.set` (ชุดสุดท้าย M15) อยู่ที่โฟลเดอร์ `Profiles/` ส่วนไฟล์ในโฟลเดอร์นี้เป็นชุดที่ใช้เปรียบเทียบ

## รหัสกรอบเวลาในไฟล์ set
`MainTF` / `HigherTF` / `SMCStructureTF` / `SMCHigherTF` ใช้รหัส MT5: 5 = M5, 15 = M15, 16385 = H1, 16388 = H4, 16408 = D1

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | กรอบเวลา | ส่วนที่ต่างจากชุดสุดท้าย | ใช้ในเอกสาร |
|---|---|---|---|
| `M5_A0_initial_SMCoff.set` | M5 | SL = ATR×2.5, ระยะ SL ขั้นต่ำ 4000 จุด, คุ้มทุนที่ 0.75R, **ปิดตัวกรอง SMC** | ฐานของการเทียบผลของตัวกรอง SMC |
| `M5_A1_initial_SMCon.set` | M5 | เหมือน A0 แต่**เปิดตัวกรอง SMC** | "M5 ชุดเริ่มต้น" (ตาราง 4.1), ฐานของตาราง 4.2, ข้อมูลฝึกโมเดล ML |
| `M5_A2_wideSL_BE0.75.set` | M5 | ขยาย SL เป็น ATR×4.0 (ขั้นต่ำ 7000 จุด) คุ้มทุนยังที่ 0.75R | ขั้นกลางระหว่าง A1 กับ A3 |
| `M5_A3_wideSL_BE1.2.set` | M5 | ขยาย SL เป็น ATR×4.0 และเลื่อนคุ้มทุนเป็น 1.2R | "M5 ขยาย SL" (ตาราง 4.1) |
| `M15_final_export-on.set` | M15 | เหมือน `Profiles/KNARES_FINAL.set` ทุกค่า ต่างเพียงเปิดการส่งออกข้อมูลฝึก (`EnableSampleExport=true`) | ชุดสุดท้าย M15 |
| `H1_wideSL_BE1.2.set` | H1 | ใช้ค่าเดียวกับ M15 แต่เปลี่ยนกรอบเวลาเป็น H1 (HTF = D1) | ตาราง 4.4 |
| `Tester_newspec_M15.set` | M15 | "spec ใหม่": รูปแบบ set ของ EA รุ่นปัจจุบัน (สัญลักษณ์เทสเตอร์ `XAUUSD`, MaxSpread 40, MagicNumber 20260601) | หัวข้อ 4.12 |
| `Tester_oldspec_M15.set` | M15 | "spec เก่า": เหมือน spec ใหม่ แต่เปิด Breakout (`EnableBreakoutEngine=true`), เปิด HMM (`UseHMMFilter=true`), ลอตตามความเสี่ยง (`LotMode=1`) | หัวข้อ 4.12 |

ค่าที่ทุกชุดใช้ร่วมกัน: เครื่องยนต์ Trend เปิด, Breakout/HMM ปิด (ยกเว้น spec เก่า), ลอตคงที่ 0.01, ตัวกรอง ML (`EnableMetaGate`) ปิด

## ตัวกรอง ML (Meta-label)
- ปิดเป็นค่าเริ่มต้น (`EnableMetaGate=false`) ผลทุกตารางข้างต้นรันโดยปิดตัวกรอง ML
- โมเดล `KNARES_Meta.onnx` ที่ฝังใน EA ฝึกบนไม้ M5 (A1) ช่วงพัฒนา+ตรวจสอบ AUC ช่วงนอกตัวอย่าง 0.547
- ฝึกซ้ำบนไม้ M15 ได้ AUC 0.508 และเมื่อนำโมเดล M5 ไปวัดบนไม้ M15 ได้ AUC 0.557 ตัวกรองที่เกณฑ์ 0.45 ไม่เพิ่มกำไรทั้งสองกรณี จึงปิดไว้

## ข้อควรรู้และข้อจำกัด
- ชุด `M5_*`, `M15_*`, `H1_*` ใช้ชื่อสัญลักษณ์ `XAUUSDm` (ระยะ SL ขั้นต่ำ 4000/7000 จุด) ส่วน `Tester_*` ใช้สัญลักษณ์เทสเตอร์ `XAUUSD` ที่ราคาทศนิยม 2 หลัก ขณะที่ `XAUUSDm` มี 3 หลัก (ระยะขั้นต่ำและ MaxSpread ในไฟล์จึงเล็กลง 10 เท่า) อย่านำค่าข้ามกลุ่มมาปนกัน ตรวจค่าให้ตรงกับสัญลักษณ์ของโบรกเกอร์ก่อนใช้
- ชุดวิจัยเปิด `EnableSampleExport=true` ซึ่งเพียงเขียนไฟล์ CSV ในโฟลเดอร์ Common ไม่มีผลต่อการเทรด ปิดได้ถ้าไม่ต้องการ
- ผลของ `Tester_*` รันบนสำเนา `KNARES_LIVE` ซึ่งต่างจาก `KNARES` เพียง MagicNumber และโค้ดวินิจฉัยที่เขียนไฟล์นับสภาวะตลาด ไม่กระทบการตัดสินใจเทรด
- ไม่มี spec ใดที่ผลเฉลี่ยต่อไม้เหนือการสุ่มซื้อ ผลกำไรช่วงหลังอธิบายได้ด้วยแนวโน้มขาขึ้นของทองคำ ช่วงนอกตัวอย่างถูกเปิดดูหลายครั้ง ตัวเลขจึงอาจดีเกินจริงเล็กน้อย
- ชุดก่อนการตรวจแก้ (pre-audit) ใช้ค่าตั้งเหมือน spec ใหม่ทุกค่า ต่างเพียง MagicNumber แต่รันบนโค้ดเก่าที่ไม่ได้อยู่ในรีโปนี้
